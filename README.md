## Sobre o projeto

Este repositório reúne atividades práticas desenvolvidas
durante a Unidade Curricular 4 do curso Técnico em
Desenvolvimento de Sistemas do SENAC.

O objetivo é aplicar conceitos de lógica de programação,
desenvolvimento de algoritmos, entrada e saída de dados,
operadores, estruturas condicionais e repetição.

Cada exercício possui um código Python e um fluxograma
representando sua lógica de execução.

## Como executar

1. Instale o Python 3.
2. Abra o projeto no PyCharm.
3. Acesse a pasta da atividade desejada.
4. Execute o arquivo `.py`.
5. Informe os dados solicitados no terminal.

## Organização dos exercícios

Cada atividade possui seu próprio diretório,
contendo o código-fonte Python e o fluxograma
correspondente em formato PNG.

## Objetivo educacional

Documentar a evolução do aprendizado em programação,
aplicando boas práticas de organização, validação de
dados e resolução de problemas utilizando Python.
